# Matched numeric-access comparison v1

Authorized read-only RTX 3090 diagnostic, existing data, W/reference frozen,
no agents, new data or training. Freeze receiver D/R, codec and every readout too.
Use parent checkpoint-0188 and pass-12 reference; no fitted probe or threshold.

## Question and fixed arms

Does the existing receiver use exact typed source counts better than literal
bytes, when keys, evidence and packet length match? Reuse all **40 existing X
Score cases /20 pairs** (categories 7/8). Keep all questions, rubric fields,
directions, targets, source facts/rules and original FP32 interval tolerances.
Training/locked data are not used; no formulas or answers are added to packets.

- **Historical baseline:** source-state evidence only, from saved captures.
- **Literal control:** add two target attributes carrying the existing required
  and completed count literals as UTF-8 bytes, each one atom.
- **Typed candidate:** the same attributes carry strictly parsed INT64 atoms.

Both new arms add exactly **eight request positions**, four per attribute. Both
keep the original source-state evidence in full. Keys, attribute order, source
bindings, question/rubric payloads and all other wire rows match. Only attribute
type/mode/body and necessary descriptor fields differ. This is one fixed
comparison, not a format search. The literal arm controls for extra keys and
positions; the historical baseline identifies effects common to both additions.

Attribute keys copy `requirement` / `complete` and the unit string verbatim from
the existing permitted count facts, with exact original byte bindings. No new
wording, quantity, unit, labels, reviewed rows or semantic judgments are authored.
The two derived canonical Key inputs are encoded by the same frozen reference
on the 3090; they are diagnostic transforms of supplied facts, not new approved
training annotations. Never put current quantity values into Key meanings.
The raw counts are used, including for reversed/half-scale rubrics; no ratio,
complement or scaled denominator is calculated for model input.

Typed values are precisely represented but their neural interpretation remains
learned. An untrained attribute path or unfamiliar keys can fail. A negative
result will not prove number information is absent or that typed values cannot
be learned. The prepared writer tick sees the actual attribute-bearing draft;
its hidden prefix may differ across arms. No cache editing/replay is permitted.

## Direction hash and old evidence reuse

Use `clean-view-v2` with explicit rubric direction, and enforce that direction
at request construction. Bind old source-only hashes by reconstructing precisely
the old four-field serialization from the v2 view; retain both identities and
the full original row hash. Never rewrite old artifacts or enable an implicit
legacy-hash fallback. Changed code is limited to view identity/validation and
an optional read-only construction hook in the existing evaluator.

Run **four source-only control anchors**: first Noul, first Choice, first Score
and first lower-direction Score. Require exact saved wire, final h, scalar/status,
actual result, transport and complete ledger. Include no new control fit.
Reuse all 40 baseline receipts; do not rerun their full diagnostic matrix.

## Execution, checks and evidence

Execute **80 new comparison cases +4 anchors**. Alternate which arm runs first
by fixed case index; this is not a throughput benchmark. Use original cached
reference slots and the same frozen source encoder. Cache fresh source states
only within this frozen diagnostic process; record actual preparation encodings,
tokens and cache hits separately from Session accounting.

Before inference verify exact numeric literal/span/atom bytes, unit/key provenance,
one-atom bodies and complete packet limits. Both arms must have identical request
roles except INT64/UTF8, exact matching non-attribute wire rows and source tensors,
the same prefill/grant and request event lengths. Capture wire/h and detailed
attribute receipts. Preserve rejected actual results in denominators; input,
numeric, identity or infrastructure violations stop with retained partial evidence.

Report all 40 cases per arm, delivered behavior, status, raw head interval hits
and distance, per-formula values, paired direction/correctness, and paired changes
against both literal control and the saved baseline. No development selection,
calibration, label revision, interval widening, retry loop or arbitrary time cap.
Verify single prefill/cache, exact P+B+A+H conservation, zero invocation text,
all 320 frozen W tensors/physical tying, reference/live/cache fingerprints and
grad=None. Existing production numeric/gradient matrices are reused because
their implementation is unchanged; new model work uses the qualified v3 path.

Acceptance means completing this measured comparison with the above invariants,
not attaining capability qualification. No production default input change,
promotion, training, native gate/reader claim or service change follows.
