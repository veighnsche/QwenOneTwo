# Matched quantity and operator receiver learning — v1

User authorization: two matched fits on existing data on the RTX 3090, W/reference
frozen, development held out, no agents or new data. No native/capability phase,
deployment, service changes or automatic follow-up fit. This protocol is fixed
before execution; results are recorded separately, including failures.

## Question and exposure

Does adapting the actual receiver to explicit count attributes improve raw count
access and use of the existing completion rubric? Compare source-literal UTF8
against parsed INT64. Preserve original source evidence and reference slots; both
arms add the same two source-bound Key references and eight request positions.
Use the existing `numeric-access-comparison-v1` transform, now with an explicit
training opt-in; its default remains read-only. No answer or calculated ratio
enters an attribute, Key, prompt or latent request.

Use **all 254 existing assessed Score receiver training rows /96 families**.
They contain denominators 20/100, 170 endpoint labels, and ordinary completion
with higher-is-better direction only. Stable protocol/seed/ID hash order,
**four full passes per arm: 1,016 presentations, 127 eight-example windows**,
without padding. Four passes test repeated receiver exposure across the complete
available quantity training set; this is a diagnostic dose, not a convergence
claim. No elapsed-time/cost cutoff, adaptive extra pass or development selection.

There are **no existing reverse-rubric or half-scale training examples**. They
remain development transfer tests. This experiment cannot measure matched
training on those absent operators. Training examples/annotations/reviews are
not synthesized to fill that gap.

## Measurements and acceptance

Record every exposure, source/reference audit, attribute bytes, heads, separate
losses, count predictions and full ledger. Measure all 254 training rows before
and after each fit; online losses are observations during fitting, not comparable
fixed-checkpoint validation. Save initial, first-update, every 32nd-window and
final checkpoints. Resume the first-update checkpoint exactly before continuing;
check model, optimizer and all RNG states. Final checkpoint is fixed, not selected.

On the second window, compare separate and combined VJPs on the same live graph:
FP32 gradient relative RMS <=1e-4, cosine >=0.99999 above the existing 1e-10
gradient floor. Require nonzero quantity-only D, atom and auxiliary gradients,
as well as combined Score-row gradients. Match initial source/reference tensors,
non-attribute wire rows and complete accounting across arms. Check all W tensors,
physical tying, reference/native ownership and grad=None. Reuse unchanged v3
matrix qualification; no repeated 324-case/1024-position qualification.

Only **after both fits finish**, evaluate all **130 E source-only retention cases**
and **180 applicable X cases**. X Score's 40 cases use each trained arm's numeric
format; Noul/Choice use their original input. Score E source-only retention is
not a numeric-format generalization panel. All 20 native-reader cases stay
excluded; locked data stays unopened. Training/development families and IDs
must be disjoint. No development-based stopping, fitting or arm promotion.

Report raw-count MAE, exact counts and nearest-integer counts separately from
existing Score interval correctness. Nearest-integer count accuracy is explicitly
diagnostic and never relaxes Score tolerances. Report ordinary completion,
reversal and half-scale error, paired direction/both-correct counts, statuses,
actual return delivery, and Noul/Choice retention. Interpret denominator200,
novel units/reference meanings and absent operators as concurrent transfer shifts.

Experiment acceptance is complete matched exposure and trustworthy evidence,
not a required improvement. A fit failure or regression remains a result. Neither
an auxiliary count readout nor forced receiver success establishes learned native
invocation, Reason semantics or complete MVP capability.
