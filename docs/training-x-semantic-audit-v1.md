# Training-to-X semantic audit v1

Read-only scope: inspect the existing approved training/development releases,
the saved 1,003 training features, 180 X captures and 620 direct-readout
predictions. Keep W/reference and every existing artifact unchanged. No agents,
new examples, annotations, reviews, model execution, fitting or training.

Acceptance:

1. Validate the pinned releases, feature files, capture receipts and predictions;
   bind each used row to its permitted role/source bytes and existing receipts.
   Keep training and development separate; never open locked data.
2. Count actual controlled task recipes, label and numeric coverage. Compare
   original and changed X sides separately, retaining the original tolerances,
   strict Noul threshold and exact FP32 Score targets. These are descriptive
   subdivisions of existing results, not replacement acceptance gates.
3. Audit which fields enter the receiver, including source quantities, rubric
   direction, candidate identities and supplied-return interventions. Compare
   the actual 3,376-view reference-fitting catalogue with the roles requested
   downstream; distinguish it from the original 500 reference rows/50 meanings.
4. Reuse the hash-bound GPU boundary measurements to distinguish exact input
   sensitivity, invariance, correct scalar effects and delivered behavior.
   Different vectors alone cannot establish preserved meaning or numeric access.
5. Record supported findings, confounders and the next unfinished slice. Preserve
   failed reports and data unchanged; do not promote a diagnostic or claim cause.

`scripts/audit_latent_semantics.py` does only metadata/receipt arithmetic. Its
strict template checks apply to the existing `controlled-data-v1` generator,
not arbitrary prose or production routing. It checks existing reviewed targets;
it creates no labels. Tensor files are hashed as opaque bytes, never loaded on
CPU. Existing GPU measurements are reused, with zero new model workloads or
Session positions. Production code/numerics remain unchanged, so completed
numeric/gradient qualifications are not rerun.
